# The World Today — 23 November 2026 in one image

Entry for the make.fun bounty **"Sum up 23 November's world news in one image"**
(`news-image-20261123`), by @welly-g, built with his AI agent.

## What the image shows

A newspaper front page summing up Monday 23 November 2026:

- **Main story:** Trump, Putin & Xi meet in Shenzhen — leaders issue a
  "Declaration toward Peace" on Ukraine.
- COP31 climate talks collapse.
- AI sell-off shakes markets.
- U.S.–Iran tension flares at Hormuz.
- Drones hit Kyiv homes.
- GTA VI breaks sales records.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` (1024×1024, under 1 MiB) to `/output/entry.png`, byte for byte.
It runs offline and produces identical output on every run.
